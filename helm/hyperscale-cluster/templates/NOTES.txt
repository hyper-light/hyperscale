Hyperscale cluster release "{{ .Release.Name }}" deployed to namespace
{{ .Release.Namespace }}.

Enabled tiers:
  Gate    : {{ .Values.gate.enabled }}
  Manager : {{ .Values.manager.enabled }}
  Worker  : {{ .Values.worker.enabled }}

This umbrella forwards values to the three sub-charts. Each sub-chart
emits its own NOTES — review them with:

  helm get notes {{ .Release.Name }} -n {{ .Release.Namespace }}

Refer to the individual sub-charts for tier-specific operations:
  helm/hyperscale-gate/templates/NOTES.txt
  helm/hyperscale-manager/templates/NOTES.txt
  helm/hyperscale-worker/templates/NOTES.txt

Reminder about cross-tier wiring:
  - The default manager.cluster.gateSeeds and worker.cluster.managerSeeds
    in this umbrella's values.yaml contain the literal token
    "{NAMESPACE_PLACEHOLDER}". You MUST replace it (typically via a values
    overlay) with the namespace the release is installed into. The chart
    intentionally does not auto-template the namespace into seed locators
    because Helm renders them as values, not as templates, when forwarding
    to sub-charts. See docs/deployment/ for the recommended overlay.
