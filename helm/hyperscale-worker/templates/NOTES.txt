Image extension:

The default hyperscale/worker image ships HTTP/1.1 in core but no
additional workload clients. Extend it for your workload:

  FROM {{ include "hyperscale-worker.image" . }}
  USER root
  RUN apt-get update && apt-get install -y --no-install-recommends \
          libpq5 && rm -rf /var/lib/apt/lists/*
  USER hyperscale
  RUN /opt/hyperscale/.venv/bin/uv pip install --no-deps \
      psycopg2-binary asyncpg my-internal-reporter

Then set image.repository to your extended image.
